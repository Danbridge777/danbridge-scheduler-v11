## 安全範圍

僅發布 Hosting。沒有改課程或學生 ID，沒有更動計費、薪資、營收歸屬、通知收件人規則，沒有部署 Functions／Rules／IAM。後端額外的可選計時 hook 只供本機量測，未部署。

使用者正在操作正式站，既有正式工作分頁不重新整理、不改篩選、不寫入正式學生／課程。所有合成學生和課程使用隔離瀏覽器或本機 Firestore Emulator；不會出現在正式學生名單。

## 本版修正

- 家教／團課左右等寬分頁、可搜尋及勾選學生的團課名單；同名學生依家長顯示與搜尋。切換保留未儲存草稿、既有團課 ID 及成員。
- 控制項 48px 高、14px 字級；標題保留層級。移除多層淡藍框與冗長常駐提示，必要計薪規則收進展開區。手機雙欄與桌面雙面板檢查不越界。
- 從個別學生的課程類型選團班時，轉入獨立團課登記，而非把既有孩子覆寫為班級。
- 最後登入時間不再阻擋已驗證角色的資料訂閱；失敗仍記錄，未完成角色驗證仍不能訂閱，換帳號期間舊回應不能套用。
- 保留開站完整 16 集合／雜湊核對、安全唯讀及角色隔離，新增讀取階段進度。無法從截圖單獨證明原先每次延遲的唯一根因，沒有宣稱所有開站延遲已消失。
- 週課表只更新課程卡片，日期、時間範圍與編輯權限相同時保留時間格；換週、清晨課或權限變更仍重建。8 次重畫後 drop 僅呼叫一次。
- 重複 canonical 排序移除；含 30,000 堂的巢狀資料回歸確認新舊雜湊相同，原始資料不變。
