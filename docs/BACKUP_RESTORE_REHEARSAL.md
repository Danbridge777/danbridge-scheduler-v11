# Danbridge 備份與還原演練

## 演練紀錄

- 日期：2026-08-08
- 環境：Firestore Emulator（獨立非正式專案 `danbridge-rules-test`）
- 正式資料：未讀取、未匯出、未修改
- 測試資料：全部使用 `TEST-` 前綴的去識別化資料
- 結果：通過

## 演練流程

1. 建立包含 16 個資料集合的測試快照。
2. 建立 JSON 備份、各集合筆數及 SHA-256 校驗碼。
3. 將 Emulator 中的主資料改為空集合，模擬資料遺失。
4. 解析備份並先驗證校驗碼。
5. 將備份寫回非正式 Firestore。
6. 比對所有集合筆數。
7. 驗證課程與學生、老師、校區的關聯。
8. 驗證補課與原課、收款紀錄與學生的關聯。
9. 比對完整還原資料與原始快照。

## 網站備份格式

網站匯出的 `Cloud Backup V3` 包含：

- `schemaVersion`
- 匯出時間與資料來源
- 16 個集合各自的筆數
- 針對完整集合內容計算的校驗碼

匯入時會先檢查集合筆數與校驗碼；不一致時停止匯入，不會取代目前資料。舊版無校驗碼備份仍可匯入，但確認畫面會明確標示為舊版。

## 重複驗證

執行 `npm run test:rules`。其中「非正式環境備份還原演練」必須通過，且不得改用 production 或 staging 專案 ID。
